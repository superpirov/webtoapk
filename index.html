📋 Как собрать APK:

  1. Скачайте сгенерированный ZIP-архив
  2. Распакуйте архив в удобную папку
  3. Убедитесь, что у вас установлен Android Studio или Android SDK
  4. Откройте проект в Android Studio или используйте командную строку: 
    cd YourAppFolder
./gradlew assembleRelease
  5. Для подписанного APK настройте keystore и выполните: 
    ./gradlew assembleRelease
  6. APK файл будет находиться в app/build/outputs/apk/release/

⚠️ Важно: GitHub Pages — это статический хостинг, поэтому полная автоматическая сборка APK требует сервера с Android SDK. Это приложение генерирует полностью готовый проект, который можно собрать локально или на CI/CD сервере.
